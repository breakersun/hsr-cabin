# hsr-cabin 🚄

在浏览器里第一人称探索**中国高铁车厢内部**的 3D 应用。移动端优先（安卓手机 / 平板为主要目标设备），桌面端完整支持。

- 技术栈：Three.js + Vite + TypeScript（全部程序化几何，无外部 3D 资产）
- 产品规格：[docs/hsr-cabin-prd.md](docs/hsr-cabin-prd.md)
- 阶段：🚧 Phase 1 MVP 开发中（二等座车厢全功能）

## 规划车型编组

司机室 · 商务车 · 二等座车 · 餐车（无一等座，见 PRD 决策记录）

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run build    # 产出 dist/
```

> 本项目为个人学习 / 作品集用途，外观致敬中国标准动车组风格，不含任何官方商标标识。
